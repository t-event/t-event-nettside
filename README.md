# T-Event – nettside

Ny nettside for **T-Event (Tustervatn Eventservice)** – DJ, lyd, lys, showlaser og spesialeffekter på Helgeland og i resten av Nordland.

- Produksjonsdomene (kobles i fase 5): https://t-event.no
- Teknologi: Astro (statisk generering), TypeScript
- Hosting: Cloudflare Pages

> Prosjektet er under utvikling. Full dokumentasjon for innholdsoppdatering
> (pakker, galleri, priser, deploy) skrives i sluttleveransen.

## Struktur (etableres underveis)

- `memory/` – prosjektminne: beslutninger, status, faste fakta
- `docs/profilhandbok/` – profilhåndboken (designfasit)
- `RISIKOER.md` – løpende risikorapport
- `RETTIGHETER.md` – rettighetsstatus for bilder og video
- `CLAUDE.md` – arbeidsinstruks for Claude Code
